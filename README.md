# formulario-bootstrap

## Objetivo

Criar um formulário demonstrativo de inscrição para uma Mostra de Tecnologia e Inovação, praticando HTML, validações nativas e componentes do Bootstrap.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.8 via CDN
- GitHub Pages (publicação)

## Campos utilizados

O formulário apresenta todos os tipos de input solicitados:

- `text`, `email`, `password`, `number`, `tel`, `url`, `search`;
- `date`, `month`, `week`, `time` e `datetime-local`: datas e horários;
- `color`, `range`, `file`, `checkbox`, `radio`, `hidden`;
- `submit`, `reset`, `button` e `image`.

Também foram utilizados `select`, `textarea`, `datalist`, `fieldset` e `legend`.

## Investigação

### O formulário salva os dados?

Não. A página é demonstrativa e não possui banco de dados configurado.

### Para que serve o Bootstrap?

O Bootstrap fornece classes prontas para organizar o formulário, formatar os campos e adaptar a página para celular, tablet e computador.

### Para que servem as validações?

Atributos como `required`, `min`, `max`, `step`, `minlength`, `maxlength`, `pattern`, `placeholder` e `accept` ajudam o navegador a verificar os dados antes do envio.
